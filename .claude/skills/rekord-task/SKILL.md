name: rekord-task
description: Convert a Rekord-Fox idea into a focused task with acceptance criteria.
---

Use this skill when turning an idea, bug, or feature request into a task.

Create a task using `tasks/TASK_TEMPLATE.md` with:

- one clear goal
- relevant docs and modules
- explicit in-scope and out-of-scope boundaries
- likely files or subsystems affected
- acceptance criteria that can be verified
- required tests, including provider simulation tests when provider or timeline
  behavior changes
- notes about architecture boundaries and deterministic behavior

Keep each task small enough for one focused Claude Code session.
